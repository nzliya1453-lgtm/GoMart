# GoMart

## Project Overview
GoMart is an Online Grocery Marketplace Management System developed using C#, Windows Forms, SQL Server, and ADO.NET.

## Features
- User Registration and Login
- Product Management
- Shopping Cart
- Order Management
- Admin Dashboard

## Technologies Used
- C#
- .NET Windows Forms
- SQL Server
- ADO.NET
